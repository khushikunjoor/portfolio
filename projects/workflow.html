Product Management

Workflow Redesign

Using product usage data to identify workflow friction, prioritize improvements, and translate insights into product requirements.

01 Discovery
02 Behavior Analysis
03 Prioritization
04 Specifications & Redesign
01

Discovery

Problem

Users were experiencing friction within core product workflows.

Evidence

Product usage data showed where users abandoned tasks or repeated actions.

Decision

Investigate workflow behavior instead of relying only on anecdotal feedback.

Outcome

A data-driven starting point for identifying workflow improvements.

02

Behavior Analysis

Evidence

SQL analysis showed differences in product usage across user roles and client accounts.

Question

Which workflows created the most friction and where were users struggling to complete tasks?

Analysis

Examined abandonment, repeated actions, and feature adoption to identify patterns.

Outcome

Identified opportunities to simplify high-friction workflows.

03

Prioritization

Problem

Not every workflow issue should receive the same product priority.

Evidence

Usage and adoption patterns helped identify which workflows affected users most directly.

Decision

Prioritize improvements where reducing friction could meaningfully improve task completion.

Outcome

A focused product opportunity rather than a broad list of disconnected feature requests.

04

Specifications & Redesign

Requirement

Reduce unnecessary steps in a key workflow while maintaining the functionality users needed.

Action

Redesigned the workflow and translated recommendations into PRDs for leadership discussion.

Measurement

Task completion rate was used to evaluate whether the redesign improved the experience.

Outcome

The redesigned workflow reduced the number of steps required and increased task completion rates.

Product takeaway

This project shows how I use product usage data to move from identifying friction to prioritizing an opportunity, defining requirements, and measuring whether a redesign actually improves the user experience.
